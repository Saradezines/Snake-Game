3. Steps to Open and Run the Project
Install Visual Studio with the .NET desktop development workload. Make sure the .NET Framework 4.7.2 targeting pack is installed.
Extract the project folder.
Open SnakeGameProject.slnx in Visual Studio (you can also open `SnakeGameProject\\SnakeGameProject.csproj`).
Wait for the solution to load.
In Solution Explorer, right-click SnakeGameProject and choose Set as Startup Project.
Press F5 to build and run with debugging, or Ctrl + F5 to run without debugging.
In the game window, choose a difficulty, then click Start Game.
To run without Visual Studio, open `SnakeGameProject\\bin\\Debug` and double-click `SnakeGameProject.exe`. Keep the `Sounds` folder next to the `.exe` so the background music can play.
4. Keyboard Controls
Key	Action
Up Arrow or W	Move up
Down Arrow or S	Move down
Left Arrow or A	Move left
Right Arrow or D	Move right
P	Pause / resume
The snake cannot turn directly back on itself. The buttons on screen (Start Game, Restart, Pause / Resume, Exit) are used with the mouse.
5. Description of Major Features
Classic Snake gameplay: the snake moves continuously, eats food, grows longer and scores points.
Three difficulty levels: Easy (220 ms per move), Medium (150 ms) and Hard (80 ms), chosen from a drop-down list before a game starts.
Random food: appears on a free cell in a random color and shape (circle, star, diamond, square or triangle). Each food gives 10 points.
Bonus food: about one in four meals also creates bonus food worth 30 points, which disappears after 35 moves.
Obstacles: up to 8 gray obstacles are placed at random, away from the starting snake.
Collision detection: hitting a wall, an obstacle or the snake's own body ends the round with a message. Filling the whole board wins the game.
Score and high score: the live score and best score are shown, and the best score is saved to a file and loaded the next time the game starts.
Pause, restart and exit: controlled with the P key or the on-screen buttons.
Sound and animation: looping background music and a snake whose eyes face its direction of travel and blink.
Smooth drawing: the board uses double buffering to reduce flicker.
OOP concepts used
Classes and objects: `Form1`, `Snake`, `Food`, `BonusFood`, `Position`
Encapsulation: private fields and private setters, accessed through methods and properties
Abstraction: the abstract class `GameObject` with an abstract `Draw()` method
Inheritance: `Food` inherits `GameObject`, `BonusFood` inherits `Food`, `Form1` inherits `Form`
Polymorphism: `Food` and `BonusFood` override `Draw()`
Composition: `Form1` contains a `Snake`, `Food` objects and a list of obstacle `Position` objects

Known Limitations
Windows only (Windows Forms on .NET Framework).
The speed does not increase as the snake grows, and a new difficulty only applies when a new game starts.
Only one high score is saved, without player names.
The `BonusFood` class is defined but not used; bonus items are created as ordinary `Food` objects.
